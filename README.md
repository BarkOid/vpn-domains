# vpn-domains

Public domain/CIDR subscription for AWG Manager on Keenetic.

Use the raw `vpn-domains.txt` URL in:

**AWG Manager → DNS routes → Subscriptions**

The list intentionally avoids routing whole CDN/provider networks such as Cloudflare. It targets only the services that should use the VPN.

Current groups:
- OpenAI / ChatGPT
- Anthropic / Claude
- YouTube
- Meta / Facebook / Instagram
- Medium
- RuTracker
- Telegram

Do not store VPN keys, router addresses, credentials, or private configuration in this repository.
